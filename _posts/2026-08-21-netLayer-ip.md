# IP地址

## IP地址分类

![IPv4 分类编址：A～E 类的网络号与主机号](/assets/2026-08-21-netLayer-ip.assets/image-20260821134550897.png)

可以看出一个ip地址由最前方几个固定的bit+网络号+主机号组成

## CIDR

假如单位要 1000 台主机：C 类太小，只能给一个 B 类，浪费几万个地址。
路由表也臃肿：很多个 C 类不能合并成一条。

所以就有了CIDR无分类域间路由(现在都是这种分配方式)

不再按 A/B/C 类固定掩码，网络有多大由斜线后的数字说了算。

无分类域间路由比如下面的192.168.0.5/24 前24位是网络号,’/‘后的24叫前缀长度,可以是任意长度

## 私有ip地址

从 IPv4 地址空间中划出一些作为私有 IP（局域网内 IP）

![私有 IP 地址范围](/assets/2026-08-21-netLayer-ip.assets/image-20260821142930700.png)

## 为什么要有私有ip地址

IPv4 一共大约 42 亿个，不够每人每台设备都占一个公网号。

于是划出三块，规定：

- 家里、公司里可以随便用
- 路由器不会把这些地址当公网目的去转发（出网时家里路由器做 NAT，把源地址换成公网 IP）
- 全世界可以重复用同一段，互不冲突(我的电脑ip是192.168.0.5 不同局域网下其他人的电脑也可以是这个ip)

### 网络号0 指定主机号

比如0.0.0.5代表的就是这个局域网下我这台电脑

就是代表这个网络内我这台电脑也就是192.168.0.5,本网内部可以用这种写法自称,路由器不会按寄给0.0.0.5转发 现在基本不用



### 全1

255.255.255.255这是本网络的广播地址,代表“所有人”,目的地址填这个本网络所有设备都会收到,路由器不往外转发

电脑开机没有ip时发送的请求目的地址就是255.255.255.255,这个不能作为源地址就很好理解了,因为发送方不能是“所有人”

### 指定网络号 主机号0

192.168.0.0 这个IP地址就是网络地址代表整片网络也就是192.168.0.0/24

看上面路由表的192.168.0.0    255.255.255.0            在链路上       192.168.0.5    291 意思不是“把包寄给192.168.0.0”而是目的落在 `192.168.0.0/24` 里（例如 `192.168.0.1`、同学的 `192.168.0.8`），从我这块网卡直接发，不用再找别的网关。所以后面是我本机的地址.

### 指定网络号 主机号全1

192.168.0.255 这是一个定向广播地址:发给 `192.168.0.0/24` 里所有主机。

和 `255.255.255.255` 的差别：

|        | `255.255.255.255`    | `192.168.0.255`                                    |
| :----- | :------------------- | :------------------------------------------------- |
| 范围   | 只在当前这一个局域网 | 指名「`192.168.0.0` 这一网」                       |
| 路由器 | 不转发               | 理论上可以从别的网定向打过来（很多路由器默认关掉） |

### 127 非全0全1

常用就是127.0.0.1又叫127网段/回环

和 Wi‑Fi 地址 `192.168.0.5` 不是同一张网。包根本不进网卡、只用软件回环口，和 Wi‑Fi 无关，在本机协议栈里转一圈。

| 你访问        | 走哪                                                         |
| :------------ | :----------------------------------------------------------- |
| `127.0.0.1`   | 本机自己，不经过 WLAN                                        |
| `192.168.0.5` | 也是本机，但走网卡自己的地址（本机到本机，多数系统仍在本机处理） |
| `192.168.0.1` | 路由器                                                       |
| `8.8.8.8`     | 先到 `192.168.0.1`，再出网                                   |

测本机服务（网站、数据库）常用 `127.0.0.1`。
源、目的都可以是 `127.x.y.z`，因为发送者和接收者都是这台电脑。
主机号一般不用全 0、全 1；最常见就是 `127.0.0.1`。

```cmd
 127.0.0.1  255.255.255.255            在链路上         127.0.0.1    331
 192.168.0.5  255.255.255.255            在链路上       192.168.0.5    291
```
